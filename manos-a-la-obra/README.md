# ¡Manos a la obra! · Reformas Chapucilla S.L.

Juego 3D de humor para navegador (three.js, sin instalación), homenaje a las telecomedias de chapuzas de los 90.
Personajes y situaciones originales.

- **Jugar:** abrir `index.html` desde un servidor (por ejemplo, GitHub Pages: `/catedral-baloncesto/manos-a-la-obra/`).
- **Controles:** WASD/flechas para moverse, Shift para correr, E/Espacio para la acción, P para pausa y M para el sonido. En el móvil hay joystick y botón «¡DALE!».
- **Objetivo:** atender los encargos de Doña Remedios durante la jornada (de 9:00 a 18:00, unos 4 minutos) con la herramienta correcta y sin hacer chapuzas.
- `?debug` en la URL expone `window.__j` para hacer pruebas.

three.js (licencia MIT) va incluido en `lib/`.
